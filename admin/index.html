Connect your repository so wallpapers can be uploaded directly to GitHub without any server.

💡 How to create a GitHub Token in 30 seconds:

  1. Go to GitHub New Personal Access Token.
  2. Set Token name (e.g. Vivid Wallpaper Studio) and Expiration to No expiration.
  3. Under Select scopes, ensure repo (Full control of private repositories) is checked.
  4. Click Generate token at the bottom and copy the ghp_... string here.
